# SmartBudget Manager

## Project Description
SmartBudget Manager is an Excel-based application designed to help users manage their personal finances by recording income and expenses.

## Main Features
- Record income and expenses.
- Organize transactions by categories.
- Calculate total income automatically.
- Calculate total expenses automatically.
- Display the remaining balance on the Dashboard.

## Workbook Structure
The workbook contains three worksheets:

1. **Dashboard:** Displays total income, total expenses, and remaining balance.
2. **Transactions:** Allows users to record their financial transactions.
3. **Categories:** Contains predefined income and expense categories.

## How to Use
1. Open the Excel workbook.
2. Go to the Transactions worksheet.
3. Enter the date, type, category, description, and amount.
4. Open the Dashboard to view the updated financial summary.

## Requirements
- Microsoft Excel 2016 or later, or a compatible spreadsheet application.
